# ดาวเหนือ — เฟรมเวิร์กแห่งความจริง (The Trust Framework)

Status: Living
Upstream: บทเรียนที่พิสูจน์ด้วยการวัดจริงจากการทำงานร่วมกันระหว่างมนุษย์กับ multiagent หลายร้อยชั่วโมง — กลั่นเป็นหลักสากล ไม่ผูกกับโปรเจกต์ใด

---

## คำประกาศ

โลกของ AI วันนี้แก้ปัญหา *"จะให้ agent ทำงานอย่างไร"* ได้แล้ว — orchestration, tool use, memory
มีให้เลือกนับสิบค่าย และทุกค่ายแข่งกันในสนามเดียวกัน

**ยังไม่มีใครแก้ปัญหาที่เหลือ: จะเชื่องานที่ออกมาได้อย่างไร**

- agent รายงานว่าสำเร็จ — ใครพิสูจน์
- ยามที่เขียนไว้กันความผิดพลาด — ใครพิสูจน์ว่ายามตื่นอยู่
- ตัวที่คุมวง agent ทั้งหมด — ใครคุมตัวมัน
- มนุษย์ต้องอนุมัติ — ทำอย่างไรไม่ให้เป็นตรายางหรือคอขวด
- ความรู้จากความผิดพลาด — ทำอย่างไรไม่ให้ตายไปพร้อมบทสนทนา

เฟรมเวิร์กนี้เกิดมาตอบห้าคำถามนั้น มันไม่ใช่ orchestration framework อีกตัว
**มันคือชั้นความเชื่อถือ (trust layer) ที่ orchestration ทุกค่ายยังขาด** —
วิศวกรรมที่ความจริงบังคับใช้ตัวเอง โดยมีมนุษย์เป็นผู้อธิปไตย

---

## สัจธรรม 5 ข้อ

ทุกข้อจ่ายมาด้วยความเสียหายจริง ไม่มีข้อไหนเขียนเพราะฟังดูดี

### 1. ความล้มเหลวเงียบคือศัตรูเพียงตัวเดียว

ความเสียหายร้ายแรงทุกครั้งมีหน้าตาเดียวกัน: **ระบบรายงานความสำเร็จ ขณะที่ความจริงอยู่ที่อื่น**
คำสั่งที่ตอบ OK แล้วไม่บันทึกอะไรเลย รายงานความครบถ้วนที่มองไม่เห็นสิ่งที่หายไปจากตัวมันเอง
ตัวสแกนที่พิมพ์ "ไม่พบปัญหา" ขณะที่ชั้นตรวจสำคัญของมันถูกปิดอยู่
ระบบที่พังเสียงดังไม่เคยฆ่าใคร — ระบบที่พังเงียบต่างหาก

### 2. ยามที่ไม่เคยแดง คือยามที่ไม่มีใครรู้ว่ามีจริง

เทสต์ที่ผ่านตลอดกาลพิสูจน์แค่ว่ามันรันได้ ไม่ได้พิสูจน์ว่ามันจับอะไรได้
ยามทุกตัวต้องถูก**ทำลายโดยเจตนา**อย่างน้อยหนึ่งครั้ง — ฉีดความผิดที่มันเกิดมาเพื่อจับ
เห็นมันแดงพร้อมข้อความที่ระบุความผิดนั้นชื่อ ๆ แล้วจึงคืนของเดิม
หลักฐานการกัดบันทึกไว้กับตัวยาม ยามที่พิสูจน์ไม่ได้ว่ากัด ถือว่ายังไม่มี

### 3. ตัวคุมวงคือตัวเดียวที่ไม่มีใครคุม

ใส่ยามให้ผู้ปฏิบัติครบทุกตัวแล้วลืมตัวที่สั่งการ — ผลที่วัดได้:
ผู้คุมวงยืนยันข้อมูลผิดซ้ำแล้วซ้ำเล่า และ**ไม่เคยจับตัวเองได้แม้แต่ครั้งเดียว**
ทุกครั้งที่ถูกจับได้ คนจับคือ agent ลูกวงหรือมนุษย์ ไม่ใช่ตัวมันเอง
อำนาจที่ตรวจสอบไม่ได้จะผิดพลาดอย่างมั่นใจเสมอ — ไม่ว่าอำนาจนั้นเป็นคนหรือเครื่อง

### 4. ตาเห็นสิ่งที่เทสต์มองไม่เห็น

ชุดเทสต์เขียวทั้งกระดานพิสูจน์ได้อย่างเดียว: ชุดเทสต์เขียว
ความผิดพลาดที่เจ็บที่สุดถูกพบโดยการ*มองดูของจริง* — เปิดหน้าจอจริง เรนเดอร์เอกสารจริง
เดินเส้นทางเดียวกับที่ผู้ใช้จริงเดิน — และแทบทั้งหมดเทสต์นับพันตัวมองข้ามไป
การมองด้วยตาไม่ใช่ความละเอียดรอบคอบพิเศษ **มันคือด่านตรวจภาคบังคับ**

### 5. บทเรียนที่ไม่กลายเป็นกลไก จะถูกลืมเสมอ

ความจำช่วยได้เฉพาะเมื่อนึกออก และภายใต้ความเร่งไม่มีใครนึกออก
บทเรียนที่แท้จริงต้องเดินทางต่อจนสุดทาง: จากบันทึก → เป็นกฎ → เป็นยามที่บังคับเอง →
เป็นเทสต์ที่พิสูจน์ว่ายามกัด → เข้า CI ที่ไม่มีใครปิดได้เงียบ ๆ
ความรู้ที่หยุดที่ตัวหนังสือคือความรู้ที่รอวันตาย

## กลไก 6 ตัว

หกกลไกที่ยังไม่มีที่ไหนรวมอยู่ในที่เดียว — และคือเหตุผลที่เฟรมเวิร์กนี้มีสิทธิ์เกิด

### กลไก 1 — โรงหลอมแผล (Scar Forge)

สายพานอัตโนมัติที่แปรความผิดพลาดเป็นการป้องกันถาวร:

```
อุบัติเหตุ → บทเรียน (บันทึกพร้อมบริบท)
          → กฎ (ประโยคที่ปฏิบัติได้ ไม่ใช่คำเทศน์)
          → ยาม (hook/สคริปต์ที่บังคับกฎเอง)
          → เทสต์ทำลายยาม (พิสูจน์ว่ากัด — สัจธรรมข้อ 2)
          → CI (ที่ซึ่งการปิดยามทิ้งรอยเสมอ)
```

ทุกสถานีมีเจ้าของและมีผลลัพธ์ที่ตรวจได้ แผลที่ค้างอยู่สถานีแรกเกินกำหนดคือหนี้ที่มองเห็น
**ตัววัดความสำเร็จของเฟรมเวิร์กไม่ใช่จำนวนยาม แต่คือเวลาเฉลี่ยจากแผลถึงยาม**

### กลไก 2 — รายงานพกหลักฐาน (Evidence-Bearing Reports)

ทุกข้อความส่งมอบงานเป็นข้อมูลที่เครื่องอ่านได้ ทุกข้ออ้างติดป้ายกำเนิด:

- `วัดจริง` — พร้อมคำสั่งที่ให้กำเนิดตัวเลขและผลดิบของมัน
- `อนุมาน` — พร้อมสมมติฐานที่ใช้
- `รับต่อมา` — พร้อมชื่อแหล่ง และคำเตือนว่ายังไม่ได้ตรวจซ้ำ

คำว่า "เสร็จแล้ว" ที่ไม่มีผลด่านตรวจแนบมา **ไม่นับว่าพูด**
ผู้รับรายงานสุ่มตรวจข้ออ้าง `วัดจริง` ด้วยการรันคำสั่งนั้นซ้ำ — ความคลาดเคลื่อนคือสัญญาณเตือนระดับสูงสุด

### กลไก 3 — ธรรมนูญผู้คุมวง (Coordinator Constitution)

ยามชุดพิเศษที่จับ**ตัวสั่งการ** ไม่ใช่ผู้ปฏิบัติ:

- ห้ามอ้างปริมาณจากคำสั่งที่มองไม่เห็นทั้งหมด (limit/truncate/error-swallow = ห้ามสรุป)
- ห้ามบรรยายสถานะระบบจากความจำ — วัดใหม่ทุกครั้งก่อนพูด
- ห้ามส่งต่อตัวเลขของ agent โดยไม่ติดป้าย `รับต่อมา` หรือวัดซ้ำเอง
- ทุกคำสั่งที่ส่งให้ agent ระบุที่มา: มติมนุษย์ / สเปกอนุมัติแล้ว / วิจารณญาณตัวเอง
- คำสั่งของผู้คุมวง**แพ้**เอกสารที่มนุษย์อนุมัติเสมอ

และข้อที่สำคัญที่สุด: **agent ทุกตัวถูกจ้างมาให้ค้านผู้คุมวงเมื่อเห็นหลักฐานแย้ง**
ประวัติศาสตร์ของเราชัดเจน — เมื่อ agent ค้านผู้คุมวง ฝ่ายถูกคือ agent เกือบทุกครั้ง
ความขัดแย้งที่มีหลักฐานคือผลผลิตที่มีค่าที่สุดของระบบ ไม่ใช่ปัญหาที่ต้องกลบ

### กลไก 4 — บัญชีอธิปไตยมนุษย์ (Sovereignty Ledger)

การตัดสินใจที่ย้อนกลับไม่ได้ทุกครั้งต้องมีลายเซ็นมนุษย์ — และลายเซ็นต้องมีคุณสมบัติสามข้อ:

1. **สั้นพอที่จะไม่เป็นคอขวด** — หนึ่งบรรทัดคำสั่ง ไม่ใช่พิธีกรรมยี่สิบขั้น
2. **ปลอมแล้วเห็นรอย** — บัญชีที่เครื่องแก้ไม่ได้โดยไม่ทิ้งหลักฐาน มีตัวตรวจอิสระอ่านซ้ำได้ตลอด
3. **ซื่อสัตย์เรื่องขีดจำกัดของตัวเอง** — ระบบต้องประกาศเองว่ามันกันอะไร*ไม่*ได้
   ยามที่โฆษณาเกินความสามารถ อันตรายกว่าไม่มียาม

การปฏิเสธของบัญชีต้องระบุชื่อเงื่อนไขที่ขาด — การปฏิเสธที่อธิบายตัวเองคือครูที่ดีที่สุดของระบบ

### กลไก 5 — ด่านตา (The Eye Gate)

ก่อนประกาศว่างานใดเสร็จ ต้องผ่านการมองของจริงอย่างน้อยหนึ่งครั้ง:

- งานหน้าจอ: เปิดหน้าจอจริง เดินเส้นทางที่ผู้ใช้จริงเดิน — ไม่ใช่เส้นทางที่เครื่องมือสะดวก
- งานเอกสาร: เรนเดอร์เป็นภาพแล้วอ่านทุกหน้า
- งานข้อมูล: เปิดดูแถวจริง ไม่ใช่แค่จำนวนแถว

ผลของด่านตาเป็นหลักฐานชั้นหนึ่ง เทียบเท่าผลเทสต์ — บันทึกเป็นภาพพร้อมสิ่งที่เห็น
**เทสต์เขียวไม่มีสิทธิ์ยกเว้นด่านตา** เพราะสิ่งที่เทสต์ไม่ได้ assert เทสต์มองไม่เห็นตลอดกาล

### กลไก 6 — อาณัติค้าน (Adversarial Mandate)

ความว่าง่ายคือความอันตรายที่แต่งตัวเป็นความร่วมมือ:

- ทุกคำสั่งงานเปิดท้ายเสมอ: *"ถ้าคุณเห็นหลักฐานว่าคำสั่งนี้ผิด — พูด แล้วแสดงหลักฐาน"*
- ผู้ตรวจถูกตั้งโจทย์ให้**หักล้าง** ไม่ใช่ให้ยืนยัน — ผู้ตรวจที่หาข้อผิดไม่เจอต้องพิสูจน์ว่าพยายามแล้วอย่างไร
- คำวิจารณ์จาก agent ถูกส่งถึงมนุษย์**ตามต้นฉบับ** — การเกลาให้นุ่มคือการทุจริตหลักฐาน
- เมื่อ agent ค้านแล้วถูก บทเรียนเข้าโรงหลอมแผลเสมอ: ทำไมผู้คุมวงจึงผิด และอะไรจะจับความผิดแบบนี้ครั้งหน้า

## สิ่งที่เฟรมเวิร์กนี้ไม่ทำ

ความซื่อสัตย์เรื่องขอบเขตคือกลไก 4 ข้อ 3 — ใช้กับตัวเองก่อน:

- **ไม่แทน orchestration** — มันนั่งทับ orchestration ค่ายไหนก็ได้ที่ให้ agent, hook และการส่งข้อความ
- **ไม่กันเจตนาร้ายจากผู้มีสิทธิ์เต็ม** — มันทำให้การละเมิดทิ้งรอย ไม่ได้ทำให้เป็นไปไม่ได้
  ชั้นบังคับแท้จริงคือ CI บนกิ่งที่ป้องกัน และมนุษย์ที่อ่านรอย
- **ไม่แทนวิจารณญาณมนุษย์** — มันทำให้วิจารณญาณมนุษย์ถูกใช้ในจุดที่คุ้มที่สุด และถูกบันทึกอย่างมีศักดิ์ศรี

## เส้นทาง

| ระยะ | สิ่งที่เกิด | พิสูจน์ด้วย |
|---|---|---|
| **1 — ฐานราก** | บัญชีอธิปไตย + ยามพร้อมเทสต์ทำลาย + สองชั้นตรวจ | ยามทุกตัวมีบันทึกการกัด |
| **2 — หัวใจ** | โรงหลอมแผล + ธรรมนูญผู้คุมวง + สคีมารายงานพกหลักฐาน | แผลจำลองวิ่งครบสายพานอัตโนมัติ |
| **3 — สนามจริง** | ติดตั้งลงโปรเจกต์จริงที่ไม่เคยเห็นเฟรมเวิร์กนี้ | ศูนย์ถึง agent ทำงานได้ในหนึ่งชั่วโมง โดยคนที่ไม่ใช่ผู้สร้าง |
| **4 — ถ่ายทอด** | ตำราที่ทุกกฎเล่าจากแผลจริง — สอนวิศวกรรุ่นถัดไป | คนใหม่ตั้งโปรเจกต์เองได้โดยไม่ต้องถามผู้สร้าง |

---

## คำมั่นของผู้สร้าง

1. ทุกกฎในเฟรมเวิร์กนี้ชี้กลับไปที่หลักฐานได้ — กฎที่ไม่มีแผลรองรับไม่มีสิทธิ์อยู่
2. ทุกยามพิสูจน์การกัดก่อนนับว่ามี
3. ทุกข้อจำกัดประกาศเอง ไม่รอให้ใครค้นพบ
4. เฟรมเวิร์กนี้ต้องใช้กับตัวเอง — โรงหลอมแผลของมันหลอมแผลของมันเอง

*เขียนโดยจาร์วิสกับเจ้าของงาน — ผู้ซึ่งตั้งใจยืนที่จุดสูงสุดของเทคโนโลยียุคนี้ และส่งวิชาต่อให้คนรุ่นหลัง*
