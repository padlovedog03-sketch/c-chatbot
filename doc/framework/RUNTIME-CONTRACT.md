# สัญญากับผู้ปฏิบัติ (Runtime Contract)

Status: Living
Upstream: [`NORTH-STAR.md`](NORTH-STAR.md) — โดยเฉพาะ **กลไก ๔ ข้อ 3** (ต้องประกาศเองว่ากันอะไรไม่ได้) และข้อ *"ไม่แทนที่เครื่องมือใด"*

---

## เหตุที่เอกสารนี้เกิด — แผลของเราเอง

ดาวเหนือประกาศว่าจาร์วิส *"วางทับสิ่งที่คุณใช้อยู่ ไม่ว่าจะเป็นอะไร"*

**ประโยคนั้นเป็นเท็จตอนที่เขียน** — วัดได้: ชั้นที่ทำงานได้จริงทั้งหมดของร่างอ้างอิงอยู่ในโฟลเดอร์ของ
ผู้ให้บริการรายเดียว ๑๙ ไฟล์ และชื่อผู้ให้บริการนั้นปรากฏใน ๒๙ ไฟล์

**และคนที่จับได้คือปัญญาประดิษฐ์จากภายนอก ไม่ใช่เราเอง** — กลไก ๖ (อาณัติค้าน) ทำงาน แต่ทำงานจากข้างนอก
บทเรียนจึงเข้าโรงหลอมแผลตามกฎ และผลลัพธ์คือเอกสารฉบับนี้ ซึ่งเปลี่ยนคำโฆษณาให้เป็นสัญญาที่ตรวจสอบได้

**สัจธรรมที่ได้เพิ่ม:** *ระเบียบวิธีที่รันได้บนผู้ปฏิบัติรายเดียว ยังไม่ใช่ระเบียบวิธี — มันคือคู่มือของเครื่องมือนั้น*

---

## ชั้นทั้งสี่

จาร์วิสแยกเป็นสี่ชั้น และมีเพียงชั้นเดียวที่ต้องรู้จักผู้ปฏิบัติ

| ชั้น | คือ | ผูกกับผู้ปฏิบัติ |
|---|---|---|
| **๐ — ระเบียบวิธี** | สัจธรรม ๕ · กลไก ๖ · ภาษาที่ใช้คุยกัน | **ไม่** |
| **๑ — แก่นไร้ผู้ปฏิบัติ** | บัญชีอธิปไตย · ด่านตรวจ · ไวยากรณ์เอกสาร · สายพานแผล | **ไม่** |
| **๒ — สัญญา** | ความสามารถ ๕ อย่างที่ผู้ปฏิบัติต้องมี และทางถอยเมื่อไม่มี | **ไม่** |
| **๓ — ตัวเชื่อม** | การต่อสายเข้ากับผู้ปฏิบัติแต่ละราย | **ใช่ — และมีได้หลายตัว** |

**ชั้น ๑ ทำงานได้วันนี้โดยไม่ต้องมีปัญญาประดิษฐ์อยู่ในห้องเลย** มันเป็นสคริปต์กับระบบเก็บประวัติ
ทีมที่ยังไม่ใช้ AI ก็ได้ประโยชน์ทันที ทีมที่เปลี่ยนผู้ให้บริการก็ไม่ต้องรื้ออะไร

---

## ความสามารถ ๕ อย่างที่สัญญาต้องการ

เขียนเป็นความสามารถ ไม่ใช่ชื่อฟังก์ชัน — เพราะชื่อเปลี่ยนทุกปี ความสามารถไม่เปลี่ยน

### C1 — การขัดจังหวะ (Interception)

*ก่อน*ที่การกระทำจะเกิด ต้องมีที่ให้แทรกกฎ และกฎนั้นต้อง**ปฏิเสธได้**

ใช้กับ: กลไก ๓ (ธรรมนูญผู้สั่งการ) · กลไก ๔ (กันการแก้บัญชีอธิปไตย)

**ทางถอยเมื่อไม่มี:** ย้ายจุดบังคับไปอยู่*หลัง*การกระทำแต่*ก่อน*การรวมงาน — ด่านก่อนบันทึกถาวร
หรือด่านกลางที่อยู่นอกมือผู้ถูกกำกับ **การป้องกันอ่อนลงจริง และต้องประกาศ ไม่ใช่ปิดบัง**

### C2 — การมอบหมาย (Delegation)

ต้องสร้างผู้ปฏิบัติย่อยที่มีคำสั่งของตัวเอง แยกบริบท และคืนผลลัพธ์กลับมาได้

ใช้กับ: การแบ่งบทบาท · กลไก ๖ (ผู้ตรวจที่เป็นอิสระจากผู้ทำ)

**ทางถอยเมื่อไม่มี:** ทำตามลำดับในผู้ปฏิบัติเดียว โดยส่งต่อผ่านไฟล์แทนหน่วยความจำ
เสียการทำงานขนานและความเป็นอิสระของผู้ตรวจ — **ความเป็นอิสระที่หายไปคือราคาที่ต้องประกาศ**

### C3 — คำสั่งที่คงอยู่ (Durable Instruction)

ต้องมีที่วางคำสั่งที่ผู้ปฏิบัติอ่านทุกครั้งโดยไม่ต้องให้มนุษย์พิมพ์ซ้ำ

ใช้กับ: ทุกกลไก — เพราะกฎที่ต้องพิมพ์ใหม่ทุกเช้าคือกฎที่จะถูกลืม

**ทางถอยเมื่อไม่มี:** ไฟล์เดียวที่มนุษย์แนบเองทุกครั้ง ใช้ได้ แต่พึ่งวินัยมนุษย์ **จึงต้องมีตัวตรวจว่าแนบจริง**

### C4 — การลงมือและการสังเกต (Execution & Observation)

ต้องรันคำสั่งได้ และ**อ่านรหัสจบงานกับผลดิบได้จริง** ไม่ใช่แค่ข้อความสรุป

ใช้กับ: กลไก ๒ (คำพูดที่พกหลักฐาน) · ด่านตรวจทั้งหมด

**ไม่มีทางถอย** — นี่คือความสามารถเดียวที่ขาดไม่ได้
ผู้ปฏิบัติที่รันแล้วไม่รู้ผล ทำให้ทุกคำอ้างเป็นเพียงความเชื่อ **สัญญาถือว่าเป็นโมฆะ**

### C5 — การรู้จบ (Completion Signal)

ต้องรู้ว่ารอบงานจบแล้ว เพื่อสรุปสถานะและรายงานสิ่งที่ค้าง

ใช้กับ: การรายงานงานเบื้องหลังที่ยังวิ่ง · การบังคับด่านตา

**ทางถอยเมื่อไม่มี:** ให้ผู้ปฏิบัติประกาศจบเอง เชื่อถือได้น้อยกว่า **ต้องประกาศว่าอ่อนลง**

## ตารางประกาศความสามารถ

ตัวเชื่อมทุกตัวต้องมาพร้อมตารางนี้ กรอกตามความจริง ไม่ใช่ตามความหวัง

| ความสามารถ | มี | ทางถอยที่ใช้ | สิ่งที่อ่อนลง |
|---|---|---|---|
| C1 การขัดจังหวะ | | | |
| C2 การมอบหมาย | | | |
| C3 คำสั่งที่คงอยู่ | | | |
| C4 ลงมือ+สังเกต | | | |
| C5 การรู้จบ | | | |

**ตัวเชื่อมที่ไม่มีตารางนี้ ไม่นับว่าเป็นตัวเชื่อม** — เพราะกลไก ๔ ข้อ 3 บังคับให้ทุกกลไกประกาศขีดจำกัดตัวเอง

---

## เกณฑ์ตัดสินว่า "พกพาได้" จริง

คำว่าพกพาได้ต้องพิสูจน์ ไม่ใช่ประกาศ:

1. **ชั้น ๐ และ ๑ ต้องไม่มีชื่อผู้ให้บริการปรากฏแม้แต่คำเดียว** — ตรวจด้วยเครื่อง ไม่ใช่ด้วยความตั้งใจ
2. **ต้องมีตัวเชื่อมที่ทำงานได้จริงอย่างน้อยสองราย** — หนึ่งรายพิสูจน์ได้แค่ว่ามันทำงานกับรายนั้น
3. **ตัวเชื่อมอย่างน้อยหนึ่งตัวต้องขาด C1** — เพื่อบังคับให้ทางถอยเป็นของจริงที่เคยเดิน ไม่ใช่ย่อหน้าสวย ๆ
4. **ชั้น ๑ ต้องรันผ่านโดยไม่มีปัญญาประดิษฐ์อยู่ในห้อง** — ถ้ารันไม่ได้ แปลว่ามันไม่ได้เป็นอิสระจริง

---

## สิ่งที่สัญญานี้ไม่รับประกัน

ใช้กลไก ๔ ข้อ 3 กับตัวเองอีกครั้ง:

- **ไม่รับประกันว่าทุกผู้ปฏิบัติจะให้ผลเท่ากัน** — ผู้ปฏิบัติที่ขาด C1 ป้องกันได้อ่อนกว่าจริง
  สัญญาทำได้แค่ทำให้ความอ่อนนั้น*มองเห็น*และ*เทียบกันได้*
- **ไม่รับประกันว่าตัวเชื่อมจะไม่ล้าสมัย** — ผู้ให้บริการเปลี่ยนรูปแบบได้เสมอ
  สิ่งที่ออกแบบให้ทนคือชั้น ๐–๒ ตัวเชื่อมคือของสิ้นเปลืองโดยเจตนา
- **ไม่รับประกันว่าย้ายแล้วไม่ต้องแก้อะไรเลย** — สัญญาลดต้นทุนการย้าย ไม่ได้ทำให้เป็นศูนย์
  ใครบอกว่าเป็นศูนย์ กำลังโฆษณาเกินความสามารถ

---

*ระเบียบวิธีที่รันได้บนผู้ปฏิบัติรายเดียว ยังไม่ใช่ระเบียบวิธี — มันคือคู่มือของเครื่องมือนั้น*
